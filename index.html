Sobre el proyecto

Desarrollo y evaluación de un sistema de trading mediante algoritmo High-Low automatizado Este repositorio contiene el código fuente desarrollado para el Trabajo de Fin de Grado (TFG) del Grado en Ingeniería y Sistemas de Datos de la Escuela Técnica Superior de Ingenieros de Telecomunicación (ETSIT) de la Universidad Politécnica de Madrid (UPM). Descripción del Proyecto El proyecto se centra en el diseño, desarrollo y validación de un sistema automatizado de negociación de activos financieros. El sistema implementa una estrategia basada en la metodología High-Low, optimizada para operar en entornos de alta volatilidad mediante la integración de criterios matemáticos avanzados de gestión de riesgos y lógica computacional. Características Principales Estrategia Algorítmica: Implementación de la estrategia High-Low para la detección precisa de puntos de inflexión en el mercado. Gestión Profesional de Riesgos: Aplicación del Criterio de Kelly fraccionado para la optimización de la asignación de capital. Adaptabilidad Dinámica: Uso del indicador Average True Range (ATR) para ajustar las bandas de negociación a la volatilidad histórica del activo. Conectividad: Integración con la API de Interactive Brokers para la ejecución de órdenes bajo condiciones de mercado. Estudio de Ablación: Análisis experimental incluido para medir la robustez de las reglas lógicas mediante la desactivación secuencial de módulos críticos. Autor Diego Rivero de la Hoz Grado en Ingeniería y Sistemas de Datos Universidad Politécnica de Madrid Licencia Este proyecto es de carácter académico. Development and evaluation of an automated High-Low algorithm trading system This repository contains the source code developed for the Bachelor's Thesis (TFG) for the Bachelor’s Degree in Data Engineering and Systems at the Escuela Técnica Superior de Ingenieros de Telecomunicación (ETSIT) of the Universidad Politécnica de Madrid (UPM). Project Description The project focuses on the design, development, and validation of an automated financial asset trading system. The system implements a strategy based on the High-Low methodology, optimized to operate in high-volatility environments through the integration of advanced mathematical risk management criteria and computational logic. Key Features Algorithmic Strategy: Implementation of the High-Low strategy for the precise detection of market inflection points. Professional Risk Management: Application of the fractional Kelly Criterion for optimal capital allocation. Dynamic Adaptability: Use of the Average True Range (ATR) indicator to adjust trading bands to the asset's historical volatility. Connectivity: Integration with the Interactive Brokers API for order execution under live market conditions. Ablation Study: Experimental analysis included to measure the robustness of the logical rules by sequentially disabling critical modules. Author Diego Rivero de la Hoz Bachelor's Degree in Data Engineering and Systems Universidad Politécnica de Madrid
