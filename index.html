Sobre el proyecto

Descripción

Desarrollo y evaluación de un sistema de trading automatizado basado en la metodología High-Low, optimizado para entornos de alta volatilidad. Implementado para el Grado en Ingeniería y Sistemas de Datos (UPM).

Características clave

  • Estrategia High-Low para detección de puntos de inflexión.
  • Gestión de riesgos mediante Criterio de Kelly fraccionado.
  • Adaptabilidad dinámica con indicador ATR.
  • Integración con API de Interactive Brokers.

Tecnologías

Python Pandas Backtesting Machine Learning
